# Retirement Calculator

A simple browser-based **retirement savings calculator** that plots your projected wealth over time using Chart.js.

**[▶ Live Demo](https://woodyhoko.github.io/tired-again)**

---

## Features

- Input current savings, monthly contribution, expected return rate, and target retirement income
- Charts projected savings balance vs. time
- Instant recalculation as you adjust parameters

---

## Stack

- Vanilla HTML + JavaScript
- [Chart.js](https://www.chartjs.org/) for the savings projection chart

---

## Run Locally

```bash
open index.html
# or: python -m http.server 8000
```
